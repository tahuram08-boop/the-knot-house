# 🧶 The Knot House

**A little place for handmade happiness!**

The Knot House is a handmade crochet e-commerce website where customers can explore and purchase beautiful crochet products made with love.

## 🌸 About the Project

The Knot House provides a platform to display handmade crochet products in one place. Customers can explore products, view details, create accounts, add products to their cart and manage their orders.

## ✨ Features

- Beautiful and user-friendly website design
- Browse crochet products
- Product gallery and categories
- Customer registration and login
- Shopping cart
- Add and manage favourites
- Customer account management
- Order history
- Order tracking
- Contact and feedback pages
- Admin dashboard
- Product management
- Order management
- Customer message management

## 💻 Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## ⚙️ How to Run the Project

1. Install XAMPP on your computer.
2. Copy the project folder into `C:\xampp\htdocs`.
3. Open XAMPP Control Panel.
4. Start Apache and MySQL.
5. Open phpMyAdmin in your browser.
6. Create the database named `knot_house`.
7. Import your project database SQL file if available.
8. Open your browser and visit:

   `http://localhost/The%20Knot%20House/`

## 🎀 Project Purpose

The purpose of The Knot House is to make handmade crochet products easier to explore and purchase through an online platform.
